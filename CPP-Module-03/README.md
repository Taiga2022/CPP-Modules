# CPP Module 03

継承と派生クラスを学ぶModuleです。

## Exercises

- `ex00: Aaaaand... OPEN!` — HP、Energy、Damageを持つ基本クラス`ClapTrap`を実装します。
- `ex01: Serena, my love!` — `ClapTrap`を継承し、異なる能力値と`guardGate`を持つ`ScavTrap`を実装します。
- `ex02: Repetitive work` — `highFivesGuys`を持つ`FragTrap`を追加し、構築・破棄の連鎖を確認します。

## Build

```sh
cd ex00 # ex00〜ex02
make
```
