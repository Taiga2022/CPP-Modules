# C++ Module 00 課題要約

この文書は `en.subject.pdf`（Version 11.2）の内容を、日本語で実装時に確認しやすい形に整理したものです。原文と食い違う場合はPDFの記述を優先してください。

## このモジュールの目的

C言語からC++へ移行し、オブジェクト指向プログラミングの基礎を学びます。主なテーマは名前空間、クラス、メンバー関数、標準入出力、初期化リスト、`static`、`const`です。

すべてのコードはC++98として有効である必要があります。

## 共通ルール

### コンパイル

- コンパイラは `c++` を使用する
- `-Wall -Wextra -Werror` を指定する
- `-std=c++98` を追加してもコンパイルできること

### 名前とファイル構成

- 演習ディレクトリは `ex00`, `ex01`, ... の形式にする
- 指定されたファイル名、クラス名、関数名を守る
- クラス名は `UpperCamelCase` にする
- クラスを含むファイルはクラス名に合わせる
  - 例：`PhoneBook.hpp`, `PhoneBook.cpp`
- 原則として、標準出力へのメッセージは改行で終える

### 禁止事項

- C++11以降の機能とBoost
- 外部ライブラリ
- `printf`系関数
- `malloc`, `calloc`, `realloc`などの `*alloc()`
- `free`
- 明示的に許可されていない `using namespace ...`
- 明示的に許可されていない `friend`
- Module 08より前でのSTLコンテナ（`vector`, `list`, `map`など）
- Module 08より前での `<algorithm>` のアルゴリズム

標準ライブラリは、上記の禁止対象を除いて使用できます。Cの関数に固執せず、C++の標準機能を優先します。

### 設計上の注意

- `new`を使った場合はメモリリークを起こさないこと
- 通常の関数実装をヘッダーへ置かないこと（関数テンプレートは例外）
- 各ヘッダーは単独で使用できるよう、必要な依存関係を自身でインクルードすること
- 二重インクルードを防ぐインクルードガードを付けること
- 必須ファイルを提出すれば、整理のための追加ファイルを作成してもよい
- MakefileにはC課題と同様のルールが適用される

## Exercise 00: Megaphone

### 提出物

```text
ex00/
├── Makefile
└── megaphone.cpp
```

### 要件

コマンドライン引数に含まれる文字を大文字に変換し、引数の順番どおり標準出力へ表示します。

```console
$ ./megaphone "shhhhh... I think the students are asleep..."
SHHHHH... I THINK THE STUDENTS ARE ASLEEP...

$ ./megaphone Damnit " ! " "Sorry students, I thought this thing was off."
DAMNIT ! SORRY STUDENTS, I THOUGHT THIS THING WAS OFF.
```

引数が一つもない場合は、次の文字列を表示します。

```text
* LOUD AND UNBEARABLE FEEDBACK NOISE *
```

### 学習ポイント

- `argc`と`argv`
- `std::cout`
- 文字列または文字配列の走査
- 大文字変換
- Cの入出力ではなくC++の標準入出力を使うこと

## Exercise 01: My Awesome PhoneBook

### 提出物

```text
ex01/
├── Makefile
├── *.cpp
└── *.h または *.hpp
```

実行ファイルには内容に合った名前を付けます。

### 必須クラス

#### `PhoneBook`

- `Contact`の配列を持つ
- 最大8件まで保存する
- 9件目以降は最も古い連絡先を上書きする
- 動的メモリ確保は禁止

固定長配列と、次の保存位置を示す循環インデックスを使う設計が適しています。

#### `Contact`

1件の連絡先を表し、次の情報を保持します。

- first name
- last name
- nickname
- phone number
- darkest secret

保存済みの連絡先に空のフィールドがあってはいけません。

クラス内部だけで使用するものは `private`、外部から操作する必要があるものは `public` にします。

### 対応するコマンド

プログラム開始時の電話帳は空です。入力として `ADD`, `SEARCH`, `EXIT` のみを処理し、それ以外は無視します。コマンドの処理後は、再び次のコマンドを待ちます。

#### `ADD`

5つのフィールドを一つずつ入力させます。すべてのフィールドが入力された後に連絡先を保存します。空のフィールドを持つ連絡先は保存できません。

#### `SEARCH`

最初に保存済み連絡先を次の4列で一覧表示します。

1. index
2. first name
3. last name
4. nickname

表示規則は次のとおりです。

- 各列の幅は10文字
- 列は `|` で区切る
- テキストは右寄せ
- 10文字を超える場合は切り詰め、表示可能な最後の文字を `.` にする
- `<iomanip>`、特に `std::setw` の使用が期待される

たとえば `123456789012` は `123456789.` と表示します。

一覧表示後、詳細を表示する連絡先のインデックスを入力させます。

- 有効なインデックスなら、全フィールドを1項目1行で表示する
- 数字でない、範囲外、未登録などの入力には適切な動作を定義する

#### `EXIT`

プログラムを終了します。連絡先をファイルへ保存する必要はなく、終了時にすべて失われます。

### 学習ポイント

- クラスとインスタンス
- `public`と`private`
- 固定長配列
- メンバー関数
- `std::getline`
- `std::setw`
- 入力検証
- 古い要素を上書きする循環処理

## Exercise 02: The Job Of Your Dreams

この演習はModule 00の合格に必須ではありません。

### 提出物

```text
ex02/
├── Makefile
├── Account.cpp
├── Account.hpp
└── tests.cpp
```

`Account.hpp`, `tests.cpp`, 参照用ログファイルはイントラネットから取得します。

### 要件

失われた `Account.cpp` を、次の情報から復元します。

- `Account.hpp` にあるクラス宣言
- `tests.cpp` が行う操作
- 参照ログに記録された出力

完成したプログラムの出力を、タイムスタンプ以外について参照ログと一致させます。デストラクタの呼び出し順はコンパイラやOSによって逆順になる場合があり、その違いは許容されます。

### 主な学習ポイント

- コンストラクタとデストラクタ
- 静的メンバー変数
- 静的メンバー関数
- 全口座数、総残高などの共有状態
- 入出金処理
- `const`メンバー関数
- 日時の整形
