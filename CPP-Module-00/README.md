# CPP Module 00

C++の基本構文、名前空間、クラス、メンバ関数、標準入出力、初期化リスト、`static`、`const`を学ぶModuleです。

## ex00: Megaphone

コマンドライン引数をすべて大文字へ変換し、順番に連結して出力します。引数がない場合は指定されたフィードバックノイズを表示します。

学習内容:

- `std::cout`による標準出力
- コマンドライン引数の処理
- `std::toupper`による文字変換

## ex01: My Awesome PhoneBook

最大8件の連絡先を保持する電話帳を実装します。`ADD`、`SEARCH`、`EXIT`のコマンドを受け付け、9件目以降は最も古い連絡先を上書きします。

学習内容:

- クラスとカプセル化
- 固定長配列
- 標準入力と入力値検証
- 表形式の文字列整形

## Build

```sh
cd ex00 # または ex01
make
```
