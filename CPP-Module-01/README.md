# CPP Module 01

メモリ確保、ポインタ、参照、ファイルストリーム、メンバ関数へのポインタを学ぶModuleです。

## Exercises

- `ex00: BraiiiiiiinnnzzzZ` — スタックとヒープに生成したZombieの寿命を比較します。
- `ex01: Moar brainz!` — `new[]`でZombieの配列を動的確保し、`delete[]`で解放します。
- `ex02: HI THIS IS BRAIN` — 文字列、ポインタ、参照のアドレスと値を比較します。
- `ex03: Unnecessary violence` — `Weapon`を参照で持つ`HumanA`と、ポインタで持つ`HumanB`を実装します。
- `ex04: Sed is for losers` — 入力ファイル内の文字列を置換し、`<filename>.replace`へ出力します。
- `ex05: Harl 2.0` — メンバ関数へのポインタを使ってログレベルに対応する処理を呼び出します。
- `ex06: Harl filter` — `switch`のフォールスルーを使い、指定レベル以上のメッセージを表示します。

## Build

```sh
cd ex00 # ex00〜ex06
make
```
